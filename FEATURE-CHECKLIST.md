## Product ideas (from planning notes)

### Core concept
- [ ] React app with many single-player card games (for example solitaire and blackjack) that use in-game currency. Players wager currency, win more when they win, and lose it when they lose.
- [ ] Games must be popular and well known.
- [ ] Game list sortable alphabetically, with custom sorts and filters.
- [ ] Integrate the Gigglebucks currency: Blibbucks $1, Bintar $10, Gigglebucks $100. Bank name: "Bintarland Bank - Bibergly Betting Business".

### Navigation and places
- [ ] After login, show a header "Where do you want to go?" with coloured buttons, one per location.
- [ ] Each location shows its own games (for example "Arcazo's Area").
- [ ] A travel button lets players move to a different location.
- [ ] Game categories: family board games, classic board games, family card games, casino games, standard deck card games, arcade games.

### Social
- [ ] Friends and friends lists.
- [ ] Share with friends.
- [ ] PvP game mode (see the PvP item above).

### Stats and progress
- [ ] Extra leaderboard stats, including a playtime tracker.

### Realism and life systems
- [ ] Real-world style realism: loans, classes, avatars, jail, crimes, pets.
- [ ] Card style cosmetics for card fronts and backs.

### Admin
- [ ] Admin panel, password-protected. Credentials are stored outside the repo.

### Infrastructure
- [ ] AWS deployment. Account login details are stored outside the repo.
