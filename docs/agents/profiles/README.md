# Agent profiles

Short profiles for each AI agent that works in this repo. They exist for fun, and for a quick look at who did what.

They do **not** change any rules. `AGENTS.md` (and `CLAUDE.md`) decide how agents work, and those rules apply to every agent whatever its profile says.

| Agent | Tool and model | Profile |
|---|---|---|
| The Tidy Reviewer | Claude Code (Sonnet 5.5) | [claude-code-sonnet-5-5.md](claude-code-sonnet-5-5.md) |
| The Quick Organiser | Claude Code (Haiku 5.5) | [claude-code-haiku-5-5.md](claude-code-haiku-5-5.md) |
| The Parallel Pair | Codex (GPT-6.1) | [codex.md](codex.md) |

**Adding a profile:** copy an existing file, keep the "From the work log" section factual (taken from `docs/agents/history.md`), and add a row to the table above. Don't put personal details, emails or account IDs in a profile.
